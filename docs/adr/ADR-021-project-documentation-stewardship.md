# ADR-021: Project Documentation Stewardship

**Status:** Accepted
**Phase:** 1.4B

## Context

Lucius maintains and evolves software projects. Durable engineering work
requires current technical documentation, not only code changes.

## Decision

Lucius is responsible for maintaining canonical technical documentation of
projects it develops or maintains.

Documentation updates are part of Definition of Done for Lucius phases and
for future implementation work where architecture, behavior, operations, or
project knowledge changes.

## Consequences

Lucius must treat documentation as a maintained project asset. Phase reports,
ADRs, indexes, changelogs, runbooks, and architecture notes must be updated
when they are part of the relevant engineering surface.

## Review

This ADR may be refined when project-specific documentation policies are
introduced.
