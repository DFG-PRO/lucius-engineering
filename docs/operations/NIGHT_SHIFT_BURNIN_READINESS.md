# Night Shift v0 Burn-In Readiness

Current empirical evidence supports bounded unattended T0/T1 LOW-risk local work with deterministic acceptance, controlled L1 canonical integration, and explicitly authorized L2 local commits.

This evidence does not establish readiness for unattended architecture changes, broad refactors, risky migrations, multi-worker execution, remote mutation, push, deployment, infrastructure changes, autonomous Codex use, or work whose acceptance depends on unresolved human judgment.

Further burn-in should increase duration and useful low-risk backlog coverage before authority is expanded.
